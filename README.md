# JH Baby Enxoval - Loja Online

Uma loja online desenvolvida com HTML, CSS e JavaScript para venda de produtos de enxoval para bebês.

## 🌐 Como Publicar Gratuitamente no GitHub Pages

Este site já está configurado para ser publicado gratuitamente usando o **GitHub Pages**. Siga os passos abaixo:

### Passo 1: Ativar o GitHub Pages

1. Acesse seu repositório no GitHub: https://github.com/gabrielwsc14-dot/Loja---Online
2. Clique em **Settings** (Configurações) no topo da página
3. No menu lateral esquerdo, clique em **Pages**
4. Em **Source** (Origem), selecione:
   - **Branch**: `main` (ou `master`, dependendo do seu branch principal)
   - **Folder**: `/ (root)` 
5. Clique em **Save** (Salvar)

### Passo 2: Aguardar a Publicação

Após salvar, o GitHub começará a publicar seu site automaticamente. Isso pode levar alguns minutos.

### Passo 3: Acessar Seu Site

Depois que a publicação for concluída, seu site estará disponível em:

```
https://gabrielwsc14-dot.github.io/Loja---Online/
```

Você pode visualizar este endereço na página de Settings > Pages após a conclusão da publicação.

## ⚠️ Importante

Este site utiliza LocalStorage do navegador para armazenar dados. Os dados são salvos apenas no navegador do usuário e não em um servidor. Se você limpar o cache/dados do navegador ou formatar o computador, **todos os dados serão perdidos**.

### Recomendações:
- Faça backup regular dos dados importantes
- Anote vendas e produtos em uma planilha separada
- Considere implementar um backend real para produção

## 📱 Como Usar Localmente

Para testar o site localmente no seu computador:

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Navegue pelas páginas da loja

## 🔄 Atualizar o Site Publicado

Sempre que você fizer alterações no código e fizer um `git push`, o GitHub Pages atualizará automaticamente seu site em alguns minutos.

### Comandos Git Básicos:

```bash
# Adicionar todos os arquivos modificados
git add .

# Criar um commit com suas alterações
git commit -m "Descrição das alterações"

# Enviar as alterações para o GitHub
git push origin main
```
