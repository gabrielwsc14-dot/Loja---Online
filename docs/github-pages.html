🌐 Como Publicar sua Loja no GitHub Pages

Guia completo para hospedar seu site HTML gratuitamente no GitHub

✅ Seu Site Está Pronto!

Todos os arquivos necessários já estão configurados corretamente. Você só precisa ativar o GitHub Pages seguindo os passos abaixo.

1 Acesse as Configurações do Repositório

  1. Vá para o seu repositório no GitHub:
    https://github.com/gabrielwsc14-dot/Loja---Online
  2. Clique na aba Settings (Configurações) no topo da página

2 Encontre a Seção Pages

  1. No menu lateral esquerdo, role para baixo e clique em Pages
  2. Você verá a página de configuração do GitHub Pages

3 Configure a Origem (Source)

  1. Na seção Build and deployment, encontre Source
  2. No dropdown Branch, selecione: main (ou master se esse for seu branch)
  3. No dropdown Folder, selecione: / (root)
  4. Clique no botão Save (Salvar)
💡 Dica: Se você não ver o branch "main", verifique qual é o branch principal do seu repositório na aba "Code".

4 Aguarde a Publicação

Após salvar as configurações:

  • O GitHub começará a processar e publicar seu site automaticamente
  • Isso pode levar de 1 a 5 minutos
  • Você verá uma mensagem na parte superior da página indicando o progresso
  • Quando concluído, aparecerá um banner verde com o link do seu site

5 Acesse Seu Site!

Seu site estará disponível no seguinte endereço:

https://gabrielwsc14-dot.github.io/Loja---Online/

Você pode compartilhar este link com qualquer pessoa para que elas acessem sua loja online!

🔄 Atualizando Seu Site

Toda vez que você fizer alterações no código e enviar para o GitHub (git push), o site será atualizado automaticamente em alguns minutos.

Comandos básicos:

git add .
git commit -m "Sua mensagem de atualização"
git push origin main
💡 O GitHub Pages atualiza automaticamente após cada push. Aguarde alguns minutos para ver as mudanças.

⚠️ Observações Importantes

  • Repositório Público: Para usar GitHub Pages gratuitamente, seu repositório precisa ser público
  • Nome do Arquivo: O arquivo principal deve se chamar index.html (já está correto!)
  • Caminhos: Use sempre caminhos relativos para arquivos CSS, JS e imagens (já está correto!)
  • Cache: Se as mudanças não aparecerem imediatamente, limpe o cache do navegador (Ctrl+F5 ou Cmd+Shift+R)
  • HTTPS: Seu site será servido automaticamente via HTTPS (seguro)

🎯 Domínio Personalizado (Opcional)

Se você quiser usar seu próprio domínio (como www.minhaloja.com.br):

  1. Compre um domínio em um registrador (como Registro.br, GoDaddy, etc.)
  2. Na mesma página de Settings > Pages, você encontrará a opção Custom domain
  3. Digite seu domínio e siga as instruções para configurar os registros DNS
💡 Esta etapa é opcional. Seu site funciona perfeitamente com o endereço github.io.

❓ Problemas Comuns e Soluções

O site não está aparecendo:

  • Verifique se aguardou os 5 minutos iniciais
  • Confirme que o repositório é público
  • Verifique se selecionou o branch e pasta corretos

As imagens não aparecem:

  • Verifique se a pasta img está no repositório
  • Confirme que os caminhos são relativos (sem / no início)

Os estilos não estão funcionando:

  • Verifique se os arquivos CSS estão no repositório
  • Limpe o cache do navegador
